## ✨ Features

- 🎯 **Kanban Board & Checklist Views**: Toggle seamlessly between a 3-stage Kanban board (*Ideas & To Do*, *In Production*, *Done & Published*) and a focused Checklist view with inline subtasks.
- 🎬 **YouTube Idea Spark Generator**: Pre-loaded viral concept templates across Tech, Productivity, Gaming, Business, and Creative niches.
- 📋 **Production Checklists**: Break down video concepts into structured production steps (Scripting, A-Roll, B-Roll, Editing, Thumbnail Design, SEO & Publishing).
- 📊 **Real-time Analytics**: Dynamic progress bars, completion rates, and subtask trackers.
- 🎉 **Celebration Confetti**: Instant animated confetti celebrations when completing tasks and goals.
- 🔍 **Instant Search & Multi-Tag Filters**: Filter by categories (`🎬 YouTube`, `📝 Script`, `🎨 Design`, `✂️ Edit`, `⚡ General`) and priority levels (`🔥 Urgent`, `🔴 High`, `🟡 Medium`, `🟢 Low`).
- 💾 **100% Offline & Persistent**: Auto-saves instantly to `localStorage` with JSON data export and import capabilities.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser, or run a local lightweight HTTP server:

```bash
# Using Python
python -m http.server 8080

# Or open directly in your browser
# Open index.html
```

Visit: `http://localhost:8080`

- **Structure**: Semantic HTML5
- **Styling**: Vanilla CSS3 (Glassmorphism, dark cyber neon theme, responsive flexbox & grid)
- **Logic**: Modular Vanilla JavaScript (ES6)
- **Celebration Effects**: Canvas Confetti
